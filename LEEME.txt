WINCARE PORTABLE v2.1
DISEÑADO POR DEVPODERSEO
=======================

1. VERSION RECOMENDADA: abre GitHub > Actions > Validar PowerShell.
   Descarga el artefacto WinCarePortable-v2.0-USB de la ejecucion
   verde mas reciente. Dentro viene WinCarePortable-v2.0.zip.
   Extrae la carpeta WinCarePortable del segundo ZIP en Ventoy.
   Tambien puedes bajar Code > Download ZIP, pero lleva pruebas y fuentes.
2. Descomprime en Ventoy:\Herramientas\WinCarePortable\
3. Inicia Windows normalmente y ejecuta INICIAR_WINCARE.bat.
4. Si WinCare pide permisos elevados, autoriza el aviso UAC para
   consultar apps aprovisionadas, características y capacidades.
   Si lo rechazas, sigue en modo limitado y puedes usar SOLICITAR PERMISOS.
   Los permisos de administrador NO habilitan desinstalaciones automáticamente.
5. Pulsa ANALIZAR PC para inventario del sistema.
6. Pulsa SEGURIDAD DE RED E IP para ver conexiones TCP/UDP, procesos,
   equipos en caché ARP/ND, IP, DNS, gateway y perfiles de firewall.
7. Pulsa HARDWARE Y SALUD para ver CPU, RAM, placa madre, BIOS/UEFI,
   discos, unidades, GPU, red, batería, dispositivos e incidencias.
   Abre msinfo32, dxdiag, Monitor de recursos, Visor de eventos y más.
   El módulo no modifica hardware ni controladores.
8. Pulsa MANTENIMIENTO para revisar antivirus, Windows Update,
   aplicaciones de inicio, disco, firewall e integridad.
9. En LIMPIEZA SEGURA elige UNA categoria: temporales del usuario,
   temporales Windows, volcados de errores, informes archivados o
   miniaturas. Escanea antes de borrar y revisa los resultados.
10. Marca uno o varios archivos o pulsa SELECCIONAR TODOS.
    Para borrar, marca la casilla HE REVISADO LOS ARCHIVOS y pulsa
    LIMPIAR SELECCIONADOS. Se pedira confirmacion. Si falta
    autorizacion, el programa indicara que casilla debes marcar.
11. El vaciado de Papelera es una accion separada con doble
    confirmacion; SFC/DISM solo verifican y no reparan.
12. Exporta informes CSV antes de realizar cambios.

WINCARE v2.1 - ANALISIS BAJO DEMANDA
- Al abrir WinCare NO se ejecuta el inventario completo.
- Selecciona Apps Store, Programas, Servicios, etc., y pulsa
  ANALIZAR PESTANA. "Analizar todo (lento)" queda opcional.
- Hardware: selecciona seccion y pulsa ANALIZAR SECCION.
- Mantenimiento, seguridad de red y soporte PC no se analizan
  al abrir; cada ventana tiene su propio boton de consulta.
- CCTV carga el catalogo, pero consulta adaptadores SOLO con boton.
- No es un monitor 24/7: sin agentes/servicios no hay alertas remotas.

CENTRO AVANZADO DE REDES v2.1
1. Abre 02 RED E IP > CENTRO AVANZADO DE REDES.
2. Pulsa ANALIZAR ADAPTADORES y elige una interfaz IPv4 privada.
3. Selecciona RED LOCAL, TOPOLOGIA, RENDIMIENTO, HERRAMIENTAS,
   WI-FI, APLICACIONES, PROTOCOLOS o CONFIGURACIONES.
4. Pulsa ANALIZAR PESTANA para esa seccion, sin analizar las otras.
5. Para ping, traceroute, DNS, puerto TCP, exploracion Wi-Fi y
   descubrimiento (maximo 16 IPv4 privadas) marca autorizacion y
   acepta una segunda confirmacion.
6. El mapa es LOGICO y estimado, no topologia real L2; la MAC
   no prueba fabricante ni existencia de intrusos.
7. Para fabricante, usa Configuracion/fabricantes-oui.csv con
   contenido por linea HEX6;Fabricante confirmado. No trae OUI externos.
8. Exporta resultados HTML/CSV. Para PDF, imprime el HTML desde
   el navegador con Microsoft Print to PDF.
9. SNMP v1/v2c/v3, NetFlow, sFlow, Syslog continuo, DPI, medicion
   SNR/heatmaps, alertas SMS/mail, backups autom. de switches y
   portal web NO ESTAN implementados: requieren servidores/sensores.

CONFIGURACIONES DE RED - HUELLA MANUAL
- En CONFIGURACIONES escribe el nombre del router/switch.
- Exporta el archivo de configuracion con la herramienta del
  fabricante y pulsa ANALIZAR ARCHIVO / COMPARAR SHA256.
- Si el archivo ya fue aprobado, usa GUARDAR REFERENCIA APROBADA
  para poder comparar exportaciones posteriores.
- Se guarda SHA256, nombre y tamano, NO el contenido ni claves.
- No realiza backup remoto automatico, acceso SSH ni SNMP.
- Un cambio de archivo debe revisarse con el administrador;
  NO demuestra por si solo que existan intrusos.

GENERAR USB AUNQUE GITHUB ACTIONS NO EJECUTE RUNNERS
- Descarga Code > Download ZIP y extrae todo en Windows.
- Ejecuta VALIDAR_WINCARE.bat para pruebas basicas sin escaneo.
- Ejecuta CREAR_ZIP_VENTOY.bat para generar
  dist/WinCarePortable-v2.1.zip en el mismo proyecto.
- Dentro del ZIP estan VERSION.txt y SHA256SUMS.txt para
  comprobacion local del paquete. Conserva tus configuraciones.

VALIDACION LOCAL SEGURA
- Ejecuta VALIDAR_WINCARE.bat desde Windows para comprobar
  sintaxis, ventanas y limites basicos SIN escanear redes ni
  desinstalar, limpiar o reparar.
- Si falla copia el mensaje de error.
- Si finaliza bien, NO confirma aun funcionamiento con cada
  impresora, camara, juego, router ni hardware real.
- Si los tests GitHub Actions no parten, revisa estado del
  runner, permisos y facturacion del repositorio.

NUEVO EN WINCARE 2.0
- Boton 08 VERIFICAR WINCARE: comprueba que todos los archivos
  esten presentes, permisos Windows, carpeta de reportes y reglas.
  Si el ZIP incluye SHA256SUMS.txt, compara su integridad.
- Steam: identifica juegos tambien desde appmanifest locales
  de bibliotecas Steam (incluso en otras unidades).
  No borra carpetas: abre Steam, que solicita confirmacion.
- El ZIP de Actions incluye VERSION.txt y SHA256SUMS.txt.
  Se excluyen configuraciones personales y reportes de clientes.
- Para actualizar, RESPALDA tus carpetas Configuracion y Reportes.
  Prueba la nueva version en OTRA carpeta antes de reemplazar.
- Una prueba de instalacion correcta NO garantiza hardware,
  redes, impresoras o desinstalaciones reales probadas.

DESINSTALACION DOTA 2 Y OTROS PROGRAMAS v2.0
1. Pulsa ANALIZAR PC > pestaña PROGRAMAS, busca "Dota 2".
2. Selecciona el juego; si el registro indica STEAM, marca
   PERMITIR DESINSTALACION (CON ADVERTENCIA).
3. Pulsa DESINSTALAR CON STEAM y confirma en WinCare y despues
   en Steam. El programa nunca borra directamente carpetas.
4. Si Dota 2 no aparece, pulsa ABRIR STEAM / JUEGOS arriba:
   Biblioteca > clic derecho Dota 2 > Administrar > Desinstalar.
5. Otros programas: MSI o asistentes permitidos; si aparece
   ABRIR EN WINDOWS, completa el proceso en Configuracion.
6. No permite quitar componentes protegidos ni programas con
   recomendacion CONSERVAR. No admite desinstalacion masiva.

LIMPIEZA TEMPORAL v1.9
El boton rojo LIMPIAR SELECCIONADOS esta en la barra SUPERIOR de
LIMPIEZA SEGURA, al lado de Seleccionar, Desmarcar y autorizacion.
Escanea > selecciona > marca que revisaste y respaldaste archivos >
pulsa LIMPIAR SELECCIONADOS > confirma.
El listado ya no debe ocultar el boton, incluso al redimensionar.
Solo elimina candidatos validados, NO carpetas completas.

13. RECOMENDACIONES: selecciona un programa en Apps Store o Programas,
    abre el modulo 05 y marca CONSERVAR o OPCIONAL; escribe el motivo,
    guarda y vuelve al inventario. Se guarda en Configuracion.
    CONSERVAR bloquea desinstalar desde WinCare. OPCIONAL no desbloquea
    componentes protegidos.
14. TALLER TECNICO: analiza el PC y exporta informe HTML/CSV,
    incluye opcion de imprimir o guardar PDF desde el navegador,
    exporta drivers con pnputil (requiere administrador) y ofrece
    reparacion guiada con doble confirmacion.
15. Solo las desinstalaciones Appx opcionales o MSI validado se permiten
   con habilitación y confirmación. No hay eliminaciones masivas.

REDES v1.6 - DIAGNOSTICO INTELIGENTE
1. Abre WinCare > 02 RED E IP > ABRIR DIAGNOSTICO INTELIGENTE.
2. El primer analisis de IP, DHCP, DNS, gateway, IPv6, Wi-Fi y
   vecinos ARP es de SOLO LECTURA.
3. Para hacer pruebas de Internet, descubrir hasta 16 IPv4 privadas,
   explorar redes Wi-Fi o probar un unico puerto TCP, marca que estas
   AUTORIZADO y acepta el aviso de cada prueba.
4. El MAPA LAN es un esquema de observaciones, no topologia fisica.
   Una IP desconocida no confirma intrusos; un ping fallido no
   demuestra que un equipo este apagado.
5. Exporta diagnostico HTML/CSV para registrar evidencias tecnicas.
   Revisa IP y MAC antes de compartirlo con clientes.

SOPORTE PC v1.7
1. Abre 06 SOPORTE PC para revisar impresoras, cola de impresión,
   errores recientes de Windows y aplicaciones de inicio.
2. El reinicio de Spooler es OPCIONAL, requiere administrador y
   DOBLE confirmacion. Puede interrumpir la impresion.
3. Guarda un historial de intervención con orden, observaciones,
   acciones y resultado; exporta HTML, JSON y CSV locales.
4. Exportar configuración guarda red/impresoras/inicio SIN
   contraseñas Wi-Fi y no sustituye un respaldo completo.

CCTV Y SEGURIDAD ELECTRONICA v1.8
1. Abre 07 CCTV / NVR. Registra cámaras, grabadores o switches PoE
   con IP PRIVADA, tipo, puerto, ubicacion y notas SIN CLAVES.
2. Selecciona el equipo, el adaptador y confirma que estas autorizado.
   Solo se enviará un PING y una comprobacion TCP a UN puerto.
3. La prueba no verifica video, ONVIF, RTSP ni grabaciones.
4. El mapa es LOGICO (según el inventario del técnico).
5. El informe HTML/CSV se genera localmente y puede contener
   IP, MAC, nombres de equipos y ubicaciones del cliente.

ADVERTENCIAS
- CCTV no escanea redes publicas, no prueba credenciales,
  no obtiene imágenes ni cambia ajustes de cámaras.
- Un puerto accesible no certifica el servicio ni el fabricante.
- No elimines trabajos de impresión ni cambies servicios sin permiso.
- Las pruebas activas hacen trafico y pueden quedar registradas.
- Ping externo 1.1.1.1, DNS example.com y HTTPS microsoft.com solo
  con autorizacion; proveedores pueden ver tu IP de salida.
- No se escanean redes publicas ni se modifican DNS, IP o firewall.
- Las recomendaciones no reemplazan la evaluación del técnico.
- Antes de reparar o exportar drivers, comprueba respaldos y espacio libre.
- SFC /scannow y DISM /RestoreHealth son reparaciones opcionales que pueden modificar Windows.
- Los volcados y reportes archivados pueden servir para investigar fallos.
- La limpieza es POR CATEGORIA, manual, no programada ni automática.
- El Liberador de espacio de Windows permite gestionar otras categorias
  oficiales (como archivos de actualizaciones) sin borrarlas manualmente.
- La limpieza no puede deshacerse de manera garantizada.
- No se borran Descargas, Documentos, controladores, cachés del navegador,
  Prefetch, Windows Update, Defender ni registro de Windows.
- Cierra aplicaciones y respalda archivos importantes antes de limpiar.
- Una IP o un proceso desconocido NO significa intruso ni malware.
- Una firma válida NO garantiza que un proceso sea seguro.
- La lista de dispositivos LAN no reemplaza la lista del router.
- Verificación IP: solo envía ping si se confirma expresamente.
- IP pública: consulta api.ipify.org solo después de confirmar.
- No hay bloqueo automático, escaneo masivo ni monitoreo continuo.
- El estado de salud y los contadores SMART pueden no estar disponibles.
- Los registros históricos de Windows no prueban un fallo actual.
- Administración de discos permite borrar particiones: usar con precaución.
- Eliminar aplicaciones podría romper funciones o borrar configuraciones.
- Respaldar datos antes de intervenir equipos.

Los reportes se guardan localmente en Reportes o Documentos.
No se ejecuta desde el menú de arranque de Ventoy.
Más información en README.md.
