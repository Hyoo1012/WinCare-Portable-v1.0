WINCARE PORTABLE v1.6
DISEÑADO POR DEVPODERSEO
=======================

1. Descarga todos los archivos desde GitHub (Code > Download ZIP).
2. Descomprime en Ventoy:\Herramientas\WinCarePortable\
3. Inicia Windows normalmente y ejecuta INICIAR_WINCARE.bat.
4. Si WinCare pide permisos elevados, autoriza el aviso UAC para
   consultar apps aprovisionadas, características y capacidades.
   Si lo rechazas, sigue en modo limitado y puedes usar SOLICITAR PERMISOS.
   Los permisos de administrador NO habilitan desinstalaciones automáticamente.
5. Pulsa ANALIZAR PC para inventario del sistema.
6. Pulsa SEGURIDAD DE RED E IP para ver conexiones TCP/UDP, procesos,
   equipos en caché ARP/ND, IP, DNS, gateway y perfiles de firewall.
7. Pulsa HARDWARE Y SALUD para ver CPU, RAM, placa madre, BIOS/UEFI,
   discos, unidades, GPU, red, batería, dispositivos e incidencias.
   Abre msinfo32, dxdiag, Monitor de recursos, Visor de eventos y más.
   El módulo no modifica hardware ni controladores.
8. Pulsa MANTENIMIENTO para revisar antivirus, Windows Update,
   aplicaciones de inicio, disco, firewall e integridad.
9. En LIMPIEZA SEGURA elige UNA categoria: temporales del usuario,
   temporales Windows, volcados de errores, informes archivados o
   miniaturas. Escanea antes de borrar y revisa los resultados.
10. Marca uno o varios archivos o pulsa SELECCIONAR TODOS.
    Para borrar, marca la casilla HE REVISADO LOS ARCHIVOS y pulsa
    LIMPIAR SELECCIONADOS. Se pedira confirmacion. Si falta
    autorizacion, el programa indicara que casilla debes marcar.
11. El vaciado de Papelera es una accion separada con doble
    confirmacion; SFC/DISM solo verifican y no reparan.
12. Exporta informes CSV antes de realizar cambios.

13. RECOMENDACIONES: selecciona un programa en Apps Store o Programas,
    abre el modulo 05 y marca CONSERVAR o OPCIONAL; escribe el motivo,
    guarda y vuelve al inventario. Se guarda en Configuracion.
    CONSERVAR bloquea desinstalar desde WinCare. OPCIONAL no desbloquea
    componentes protegidos.
14. TALLER TECNICO: analiza el PC y exporta informe HTML/CSV,
    incluye opcion de imprimir o guardar PDF desde el navegador,
    exporta drivers con pnputil (requiere administrador) y ofrece
    reparacion guiada con doble confirmacion.
15. Solo las desinstalaciones Appx opcionales o MSI validado se permiten
   con habilitación y confirmación. No hay eliminaciones masivas.

REDES v1.6 - DIAGNOSTICO INTELIGENTE
1. Abre WinCare > 02 RED E IP > ABRIR DIAGNOSTICO INTELIGENTE.
2. El primer analisis de IP, DHCP, DNS, gateway, IPv6, Wi-Fi y
   vecinos ARP es de SOLO LECTURA.
3. Para hacer pruebas de Internet, descubrir hasta 16 IPv4 privadas,
   explorar redes Wi-Fi o probar un unico puerto TCP, marca que estas
   AUTORIZADO y acepta el aviso de cada prueba.
4. El MAPA LAN es un esquema de observaciones, no topologia fisica.
   Una IP desconocida no confirma intrusos; un ping fallido no
   demuestra que un equipo este apagado.
5. Exporta diagnostico HTML/CSV para registrar evidencias tecnicas.
   Revisa IP y MAC antes de compartirlo con clientes.

ADVERTENCIAS
- Las pruebas activas hacen trafico y pueden quedar registradas.
- Ping externo 1.1.1.1, DNS example.com y HTTPS microsoft.com solo
  con autorizacion; proveedores pueden ver tu IP de salida.
- No se escanean redes publicas ni se modifican DNS, IP o firewall.
- Las recomendaciones no reemplazan la evaluación del técnico.
- Antes de reparar o exportar drivers, comprueba respaldos y espacio libre.
- SFC /scannow y DISM /RestoreHealth son reparaciones opcionales que pueden modificar Windows.
- Los volcados y reportes archivados pueden servir para investigar fallos.
- La limpieza es POR CATEGORIA, manual, no programada ni automática.
- El Liberador de espacio de Windows permite gestionar otras categorias
  oficiales (como archivos de actualizaciones) sin borrarlas manualmente.
- La limpieza no puede deshacerse de manera garantizada.
- No se borran Descargas, Documentos, controladores, cachés del navegador,
  Prefetch, Windows Update, Defender ni registro de Windows.
- Cierra aplicaciones y respalda archivos importantes antes de limpiar.
- Una IP o un proceso desconocido NO significa intruso ni malware.
- Una firma válida NO garantiza que un proceso sea seguro.
- La lista de dispositivos LAN no reemplaza la lista del router.
- Verificación IP: solo envía ping si se confirma expresamente.
- IP pública: consulta api.ipify.org solo después de confirmar.
- No hay bloqueo automático, escaneo masivo ni monitoreo continuo.
- El estado de salud y los contadores SMART pueden no estar disponibles.
- Los registros históricos de Windows no prueban un fallo actual.
- Administración de discos permite borrar particiones: usar con precaución.
- Eliminar aplicaciones podría romper funciones o borrar configuraciones.
- Respaldar datos antes de intervenir equipos.

Los reportes se guardan localmente en Reportes o Documentos.
No se ejecuta desde el menú de arranque de Ventoy.
Más información en README.md.
